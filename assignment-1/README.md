# Assignment 1 – Personal CV Page

A single-page personal CV built with semantic HTML5 and an external CSS stylesheet. It uses no JavaScript and no frameworks.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | CV content using semantic HTML5 elements |
| `styles.css` | All styling (external stylesheet, no inline styles) |
| `images/profile.svg` | Placeholder profile photo |

## Requirements covered

- **Header:** name, tagline and photo (`<header>`, `<img>`)
- **Navigation:** links to each section (`<nav>`)
- **About Me, Education, Skills, Projects, Leadership, Contact:** each is a `<section>` inside `<main>`
- **Education:** a semantic `<table>` with `<thead>` and `<tbody>`
- **Projects:** each project is an `<article>`
- **Contact:** a `mailto:` link plus LinkedIn and GitHub links
- **Footer:** `<footer>`
- **Box model:** margin, padding and borders on the header, nav, main box, sections, project cards and table cells

## How to view

Open `index.html` in a browser.
