# Assignment 1 – CV in HTML & CSS

A personal CV (résumé) built with plain HTML5 and CSS3. It uses no frameworks or JavaScript.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | CV content, marked up with semantic HTML (`header`, `aside`, `main`, `section`, `article`, `footer`) |
| `style.css` | Styling: CSS variables, Grid and Flexbox layout, skill bars, responsive and print rules |

## Features

- Two-column layout (sidebar + main content) built with CSS Grid
- Responsive: stacks into one column on screens narrower than 760px
- Print-friendly: use **Print → Save as PDF** in the browser to export the CV
- Colors are defined once as CSS variables in `:root`, so the theme is easy to change

## How to view

Open `index.html` in any web browser.

## Customizing

Replace the placeholder text (email, phone, university, dates such as `20XX`, projects and experience) in `index.html` with your own details.
